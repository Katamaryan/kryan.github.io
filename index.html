About Me

Hiya, my name's Ryan and I am an aspiring game programmer and designer, with a leaning towards programming, I'm currently a student at the University of Staffordshire on the Computer Games Design and Programming course in the second year. My main focus is on gameplay programming with a preference for working in C# for Unity but i have experience with both blueprint and C++ in Unreal Engine and now a little bit of html from making this website

I have a few projects completed so far, shown below. With more in progress and to come in the future namely a group project I'm currently working on with a few friends and a personal project I'm looking forward to working on is attempting to rebuild the game SCP: Containment Breach in Unity for fun and to see if i can do it. Most of my projects so far are student work but I'm getting into the habit of working on my own wtuff as well as i get more confident in working in engines and using the different programming patterns effectively
